## Top-level description

This repository is a **GitHub Skills course template**, not an application. Its product is a
guided learning experience: a learner creates a repository from this template, and the course
then advances itself through five steps by rewriting the learner's own `README.md` in response
to the Git actions they perform.

The repository is therefore best read as a **state machine whose state lives in git** and whose
transitions are GitHub Actions workflows. Nothing here builds, runs or serves.

`README.md` at the repository root is the **rendered surface** of the state machine: it is the
course entry point in the template, and in a learner's copy it is the file the transition action
rewrites on every step.

## Communication map (the state machine)

State cursor: **`.github/steps/-step.txt`**, currently `0`.

Every workflow follows one shape: a `get_current_step` job reads the cursor, and the main job runs
only when `!github.event.repository.is_template && current_step == N`. The `is_template` guard is
what stops the course from advancing inside this template repository itself.

```
   trigger                     workflow                        transition
   ────────────────────────────────────────────────────────────────────────
   push to main            →   0-welcome.yml               →   step 0 → 1
   create (branch)         →   1-create-a-branch.yml       →   step 1 → 2
   push                    →   2-commit-a-file.yml         →   step 2 → 3
   pull_request            →   3-open-a-pull-request.yml   →   step 3 → 4
   push (merge to main)    →   4-merge-your-pull-request.yml → step 4 → X
```

Each transition calls `skills/action-update-step@v2` with `from_step`, `to_step`, the
`GITHUB_TOKEN`, and `branch_name: my-first-branch`. The action swaps the learner's `README.md`
body for `.github/steps/<to_step>-*.md` and advances the cursor. `X` is the terminal state and
publishes `.github/steps/X-finish.md`. Every workflow also carries `workflow_dispatch`, so any
step can be re-fired by hand. Required permission throughout: `contents: write`.

The coupling to watch: **a step's prose, the workflow that publishes it, and the cursor value it
gates on are three files that must agree.** Renaming a step file, renumbering a workflow, or
editing `-step.txt` in isolation breaks the chain silently — the learner simply stops advancing,
with no error surfaced anywhere.
